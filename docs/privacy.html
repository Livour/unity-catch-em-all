Privacy Policy: creator-workshop

Last updated: 2026-10-31

creator-workshop is a personal tool used only by the YouTube creator Livour to read analytics for their own channel. It is not offered to the public.

What it accesses

With the channel owner's sign-in, it reads YouTube channel data and YouTube Analytics reports (views, watch time, impressions, search terms) and the owner's own TikTok profile stats and video list, using read-only Google API scopes. When the owner explicitly asks, it can also upload videos to the owner's own channel.

How data is used and stored

Data is saved only on the owner's own computer and used only to plan and improve the owner's videos. It is not sold, shared, or sent to third parties, and it is not used for advertising.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions: open an issue at github.com/Livour/unity-catch-em-all.
